# 全量图片的声明接地性与FG-CLIP阈值实验

本轮对SA1B目录内全部4848张原图，用原始LLaVA-1.5-7B生成图片描述，
DiscoSG拆分并保存完整图结构与对象存在性声明。19392张裁块不作为独立样本，
图表等非数据图片不进入实验。模型、图片列表、分组和随机设置写入冻结计划。
本轮固定原图裁判及全图FG-CLIP分数；裁块留作后续需要时的局部核验，不混入本轮阈值搜索。

## 数据与统计范围

每张图先落盘原始回答、生成token IDs及参数；DiscoSG保存所有原始图结构、
对象候选、源文本跨度和不能对齐的原因。后续阈值分析只解释可可靠定位的、
肯定语境下的对象存在性声明，不代表已经覆盖属性、关系或所有自然语言幻觉。

原来训练/校准用过的图片及其内容重复图归入`retrospective`，单列回顾性结果。
新的`formal`图片按图像内容分组，提前冻结`dev`/`test`划分；同图及重复图不能跨组。
所有原图仍生成、解析并保留，包括没有可用声明的图片；有效覆盖率另行统计。

## 图像裁判与分数

使用独立于LLaVA生成器的具备视觉能力的大模型。每个请求实际包含图片，
同图全部有效声明一起判别，每条声明分别返回`case_id`、三态标签和简短视觉依据。
裁判看不到FG-CLIP分数、原阈值和旧弱标签；不因API或解析失败生成真伪标签。

- `supported`：图中证据支持存在。
- `unsupported`：可观察证据足以判定声明不成立。
- `uncertain`：小目标、遮挡、类别/范围含混或证据不足。

裁判输出是模型参考标签/银标，不是人工GT。原始回复、服务返回模型名、请求ID、
用量、失败与重试均保存在逐图日志。模型一致或单次评分不等于事实保证。

裁判API与本地FG-CLIP计算在准备完成后并行运行。主条件为固定FG-CLIP权重、
原始对象词、`global`余弦分数与`walk_type=short`，不根据测试表现更换文本模板或分数模式。
不使用原来的正负阈值预筛选：所有符合文本对齐条件的对象声明均请求裁判、计算原始分数，
声明是否保留不依赖旧弱标签或FG-CLIP分值。此次从完整分数范围重新寻找阈值。

## 阈值选择与验证

阈值仅由`formal/dev`选择，在冻结的`formal/test`上验证。
同时报告最大F1的探索工作点及高精度正/负双阈值；未决标签保留弃权，
没有满足精度/最低样本约束的负阈值时允许返回禁用，不提高阈值凑数量。
高精度点的统计筛选不构成搜索后的精度保证；图像分组bootstrap等区间仍不包含裁判误差。
回顾性图片不用于选择正式工作点。

## 执行与恢复

计划位于实验根目录的`details/plan.json`，输入清单位于`details/inputs.jsonl`。
在已配置API环境变量的模型环境中运行：

```bash
python run/run_grounding_calibration.py --run /root/autodl-tmp/output/EXPERIMENT
```

阶段依次为生成、DiscoSG分解、声明准备、裁判与FG-CLIP并行、按ID合并、分析。
生成按批次、分解按记录保存原子校验分片，断点验证原始输入及模型/配置后继续。
若生成器正在独立运行，流程会等待该阶段锁，再复用其已完成分片。
裁判按逐图日志恢复，仅重试未成功项目；FG-CLIP已有完整且来源匹配的分数时复用。
输入、分组、图片、模型或提示改变应另开实验，不混合不同协议。

结果目录只需查看：

```text
results.md       # 阈值、精度、召回、覆盖与限制
results.json     # 程序可读的最终结果
details/         # 计划、输入、全部回答/声明、裁判、分数、日志和图形
```

运行中根目录展示进度；分析器发布最终报告后，编排器只更新`details/status.json`，
不会用进度页覆盖最终结果。任何声明裁判失败均记录为失败，不通过删掉难例来完成实验。
