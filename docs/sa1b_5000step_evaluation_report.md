## 观察

5000步没有整体优于100步。AMBER覆盖率提高，但生成式幻觉指标变差；MMHal和ObjectHal同样变差。POPE adversarial准确率基本不变，Precision下降。当前结果不支持将最后一步默认视为最优检查点。

训练使用同一256条固定自动反馈池，累计5000次更新，从100步继续4900次；没有刷新反馈。上述现象还不足以定位原因，需要区分反馈质量、正负样本覆盖及训练步数等因素。
