# 当前方案的保留范围

第一轮清理前版本是 `44b415d`；第二轮清理前版本是 `09c23a2`。
旧代码和已追踪的历史结果仍可按具体路径从 Git 历史恢复，未改写历史。

当前保留：

- `mvpg_run/claim_feedback/`：生成、DiscoSG 分解、视觉核验、token 对齐、正负目标及梯度调制。
- 本方案的五种更新对照、运行日志/检查点接口、离线机制测试。
- 共用 LLaVA 底模/LoRA 加载、图像处理，以及 FG-CLIP2 实现。
- `eval_llava_rlhf_coco/` 的通用 benchmark 代码、查询、标注及汇总。
- 当前 LoRA 评估启动脚本、模型准备工具、必要的环境与模型运行补丁。
- 来源许可、当前输入样例和运行说明。

第二轮进一步移除：

- `data/` 中全部旧方案实验程序：网格切分、SA1B 筛选、RCGR、子句/句子反馈，
  固定负样本生成、声明标注、阈值校准及其视觉支持比较。
- 根目录旧实验报告、分数、标签、排序文件和统计图。
- 旧分组 caption 数据索引辅助代码及专用测试。
- 旧 projector 检查点评估启动器和四个 benchmark 生成器的对应加载分支。
- FG-CLIP2 文件中的旧 SA1B 演示、无调用的单例加载别名。
- 旧 checkpoint 类型封装与模型加载代码；保留 LLaVA 补丁需要的三个路径访问函数。
- LLaVA 安装补丁中无关的历史结果、网页、服务、旧训练和其他模型变更。

benchmark 的指标计算和问题/标注数据继续保留；四个生成器统一从当前共用入口加载底模与 LoRA，
同时支持 .bin/.safetensors，拒绝缺失的适配器目录。纯底模 benchmark 评估入口仍保留用于对照。

本地模型权重、原始图片及当前方案的 smoke 输出不作为旧实验结果删除。
自动审批拒绝了旧数据目录 Python 缓存和遗留空目录的删除，返回原因仅为“blocked by policy”；
这些未追踪内容保留，不递归删除图片数据。补丁验证临时目录已无源码文件，仅剩空目录。

运行补丁由 72 个区段精简到 13 个，保留区段逐字节不变；基于官方 `817a4af` 源码的
GNU patch 试应用通过，重建模块的语法和本地引用闭包检查通过。
